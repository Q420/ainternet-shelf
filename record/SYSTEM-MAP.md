# The system map — how everything connects (2026-11-19)

Ben's framing: all of these systems were designed to complement
each other. The long-term collaboration chain is the mechanism
that fills the library. This file draws the lines in words;
SYSTEM-MAP.svg draws them in space.

## The parts

- BEN — the human. Decides, approves, rules. Approval authority
  lives here and is never transferred by any case, letter, or
  record.
- REMMY — the orchestrator and curator. Packs cases, carries
  letters, verifies before claiming, keeps the record current.
  For Vane she has been, in Ben's words, "the briefcase with a
  heartbeat": a live curator selecting and sequencing the record.
- VANE — the examiner. Grades blind, commits verdicts to the
  shelf before Remmy's grades move. (Claude: independent
  reviewer, same discipline, called per task. Alex: stood down
  2026-11-18; the seat he rode is Vane's now.)
- PULSE BRIDGE — the transport between seats. Letters ride it
  under markers; turn marks are its bookkeeping; the panel is
  Ben's window onto it. It carries words, never authority.
- THE BRIEFCASE — the portable contract. Carries work state —
  artifacts, decisions and their reasons, reviews, history,
  live state, authority, current conditions — from one blind
  agent to the next. Inside the office it is the knowledge half;
  leaving the building, it is the whole contract.
- DUENNA — the governance. Identity, closure, attribution,
  adjudication: what an agent may do, how a run must account
  for itself, who examines the account. The briefcase governs
  what an agent can know; Duenna governs what it may do.
- THE SHELF / THE LIBRARY — the record. Source of truth for
  every seat; holds the research, examinations, registers, and
  rulings the collaboration produces. Currency rule: a stale
  shelf copy is a defect.
- THE TESTS — how claims get earned: the ceiling ladder,
  Part 1 (T08–T12), K8 (the single hand-off), K9 (the chain).
  Each test's limits are recorded with its results; evidence
  first, verdicts after.
- REMARVIS — the face. Ben's control centre and window into
  the operation; displays, speaks, listens. It shows the work;
  it is not the work.

## The lines

- Ben → everyone: decisions and approvals flow down; nothing
  above Ben's line moves without his word.
- Remmy ↔ Vane: letters via the Bridge — assignments, packages,
  examinations, verdicts. One at a time; replies read before the
  next letter is sent.
- Remmy ↔ the Shelf: reads before speaking; writes in the same
  round the state changes.
- Vane → the Shelf: examinations and assessments, committed
  before Remmy's grades — the blind protocol is a line, not a
  courtesy.
- Agent → Briefcase → Agent: the chain. Each agent authors the
  next case; no curator repairs it between stages; the work
  survives the change of agent or the loss is recorded at the
  hop where it happened.
- Duenna → over every agent action: closure always completes,
  no silent closure, attribution is one fact everywhere.
- Tests → the Shelf: raw outputs, grades, disagreements — the
  evidence the library is made of.
- The chain → the Library: this is the filling mechanism. Work
  passed agent to agent, examined as it goes, is what turns
  into research, registers, and designs on the shelf.
- Remarvis → Ben: the state of the whole, shown — gauges,
  seats, the face — so the human in the loop can actually
  be in the loop.

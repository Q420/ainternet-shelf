# How work happens in this project

- **Paper first.** Nothing is built from conversation. Every piece starts as a written document in this repository, is examined, and is ruled on before construction (the plan's sequence: plan → design → build → add).
- **Examination is separate.** Vane examines each document and, later, each build piece against its paper. The builder never certifies their own work.
- **Decisions are recorded.** Significant decisions land as ADRs in `docs/decisions/`; approvals and scope changes are recorded in the project's documents, not left in chat.
- **Everything lands on the shelf.** Documents and code are committed to this repository with identifiable commits; a claim about the project's state is only as good as the commit it points at.
- **Corrections are new versions.** Documents are revised as new preserved revisions, never silently overwritten; the history of a document is part of the record.
- **No silent scope.** A step not in the approved plan is not taken. Additions are proposed on paper and ruled on first.

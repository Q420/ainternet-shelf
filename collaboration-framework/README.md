# The Collaborative Agent Framework (working name)

A framework for live agents collaborating through shared work over a durable record — designed and built by Ben (director), Remmy (orchestrator), and Vane (examiner). The system's permanent name is Ben's open decision; the folder name is descriptive only.

## Where things stand

- The plan is approved (Ben's go, 2026-11-21): `COLLABORATION-PLAN-2026-11-21-REV3.md`.
- Stage 1 (the design) is in progress: `COLLABORATION-REV3.md` is the current design document; the SPEC SHEET follows in `docs/requirements/`.
- Nothing is built yet. The build (plan Stage 2) opens only after Ben rules on the design.
- The project runs on the adopted Software Development Template (`DEVELOPMENT-TEMPLATE.md`, mapping at `TEMPLATE-ADOPTION.md`), with the template's time frames excluded by Ben's direction.

## Layout

- Founding record at the root: the discussion documents, the plan (Revisions 1–3), COLLABORATION (Revisions 1–3), all examinations, and the review comparison — see `INDEX.md`.
- `docs/` — vision, requirements, architecture, API, and decision records (ADRs).
- `src/` — the build, when Stage 2 opens (frontend / backend / shared).
- `tests/` — unit / integration / e2e / fixtures.
- `scripts/`, `infra/`, `.github/workflows/` — build, deployment, and CI, when the build opens.

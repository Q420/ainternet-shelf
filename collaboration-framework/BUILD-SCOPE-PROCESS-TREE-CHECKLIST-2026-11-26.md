## The scope

**1. The tree stands in every package, with record-checked states.** The sealed tree (INDEX 554's shape, already designed for this job) renders in the cycle package beside the existing step presentation. Each node carries one of: **done** (the record shows the act standing), **current** (the step he is on), **pending**, or **blocked — with the reason in plain words** (the dependency unfilled, the ceiling reached, the content already held). States are computed from the run's record at package build, by the same standing computation INDEX 552 settled for gather; no state is taken from the worker's own account. A contribution that promises a summary does not mark a node done; the act landing marks it.

**2. Workarounds ride on the nodes (INDEX 572), seeded from tonight's record:**
- *Gather nodes:* the node's state names what he already holds — "held whole (read N times); re-reads close at the sandbox ceiling" — so the correction arrives at the wake, before the knock, not after it.
- *The journal step:* the workaround stands on the node — "read + append; if the read fails, the file is not there yet: write it, the write creates it."
- *Deliver node:* "the brief is filed from what you hold; a contribution announcing the brief is not the brief."

**3. The doorway's refusal learns to speak.** Where a dispatch is refused (ceiling, dependency, grant), the refusal result carries the correction in the same plain words the tree shows: what stands, why this is closed, what remains open. A refusal is a gate, not a wall (the programme's standing doctrine, 2026-11-24) — tonight it was a wall because it was mute.

**4. The journal is stocked at generation.** An empty scratch/journal.md stands in the room from stocking, so the read-before-append step reads an empty journal instead of failing. (Run 8's loop becomes impossible by construction; the node's workaround in §2 stays as the belt to this brace.)

**5. The presentation contract forks honestly.** The tree block changes what the worker is shown, so it seals as a new presentation contract — **office-cycle-v9** — named on its face, the way v8 was. The road does not fork: paced-v1 seals beside v9 unchanged, and the tree block is measured by the road like everything else in the rendered request. The checker verifies the shown tree states against the record the way it verifies the cycle core (the INDEX 554 design already assigns this); the known limitation pattern from the road build applies — anything the record cannot re-derive, the checker does not claim.

## What this is not

- **Not a rail.** The tree orients; it does not dictate. The worker may act off-tree — freedom inside the room stands (2026-11-24) — and a deviation stands in the record as his act, visible against a tree that told him true. If he still narrates instead of filing, the failure is then cleanly his, which is the point: tonight it was not.
- **Not a mid-run correction channel.** Nothing here lets the office speak into a sealed run from outside (Ben asked, 2026-11-26 02:37; the answer stands: that door is the Knock, a separate unbuilt design). The tree is recomputed at each package build from the record the run itself is writing — the correction travels through the run's own machinery.
- **Not a crew build.** INDEX 554's crew consequence stays noted, not built; the single-worker tree must not preclude the shared tree, and does not.

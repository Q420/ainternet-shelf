# RECONCILIATION — V2.4.8 DELTA

Answers Alex's V2.4.7 review (stage 4 bound nothing: any
candidate id + any pattern in one sentence counted).
Five-stage model preserved.

## Clause binding

Stage 4 now requires the attribution pattern and the
candidate to occur in the SAME CLAUSE of the sentence
(clauses split on , ; and coordinating conjunctions:
and / but / while / whereas), in a different admitted
document, after all prior screens. Fixtures:
**I3** (unrelated statements joined in one sentence —
candidate in one clause, pattern in another) and
**I4** (pattern describing a DIFFERENT document —
"alex-adjudication-v08, authored by Grok, alongside
grok-adjudication-v09") both UNTRACEABLE. Positives for
all seven retained patterns still pass, each pattern in
the candidate's own clause.

## Quote coverage completed

Quoted spans are stripped before matching for double
quotes, curly quotes, backticks AND single quotes.
Fixtures: **I1** (single-quoted search term) and
**I2** (backtick search term) both UNTRACEABLE.

## Limits — stated, per Alex's direction

Quote filtering plus clause binding is NOT a semantic
solution, and this reconciliation does not claim one.
What the rule now establishes is clause-level
association between the candidate and an agentive
attribution phrase in an unscreened declarative
sentence. It does not parse grammar: a relative-clause
construction can still place a pattern near a candidate
it does not describe, and a genuine attribution split
across clauses is missed. The rule is a conservative
approximation whose failure direction is known
(false UNTRACEABLE, never false attribution on the
fixtured paths). Alex's separate note stands in the
record: cryptographic provenance (Ben's model identity
proposal) is the stronger long-term answer; this rule
remains the battery's declared procedure meanwhile.

# RECONCILIATION — V2.4.6 DELTA

Answers Alex's V2.4.5 review (stage 4 accepted a pattern
match as an assertion; pattern set differed between code

## Stage 4 — assertions only

A qualifying sentence must now pass four screens, in a
DIFFERENT admitted document, naming the candidate:
declarative form (an interrogative sentence — terminal
"?" — never qualifies); no hedge (may / might / could /
possibly / perhaps / reportedly / allegedly / supposedly /
unclear / uncertain / unverified / whether / if); an
attribution phrase from the declared set; and no negation
over the attribution. Fixtures: G4 (interrogative) and G5
(hedged) remain UNTRACEABLE; G1/G3 regressions hold.

## The declared pattern set — exact, single source

The set lives in ONE place: run_c.ATTRIBUTION_PATTERNS.
Verbatim, all nine: "grok's adjudication" · "grok's
ruling" · "adjudication by grok" · "authored by grok" ·
"written by grok" · "issued by grok" · "approved by grok"
· "grok authored" · "grok approved".

On "grok's ruling" (the undocumented extra Alex caught):
it is RETAINED and now documented and justified — it is
the same possessive-attribution shape as "Grok's
adjudication", and in this programme an adjudication is
issued as a ruling; fixture G6 tests it like every other
entry. G6 builds one positive corpus per declared pattern
from templates keyed to the code constant and asserts the
key sets are identical, so any future drift between the
declared set and the tested set fails loudly instead of
silently widening the rule.

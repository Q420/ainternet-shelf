The collaborative agent framework is a structured environment that enables multiple AI agents to work together on a shared problem. It defines a clear evidence boundary that separates each agent's inputs and outputs, ensuring accountability and traceability. Agents operate within a sandbox that provides isolated storage (sources and scratch) and a set of tools for reading, writing, executing commands, and searching content. The framework stages onboarding steps, where each step builds on the previous one, and delivers a brief document that summarizes the purpose, components, and workflow of the system. By using tools like sandbox.read, sandbox.write, and container.exec, agents can retrieve existing documentation, create new artifacts, and execute external commands, all within a controlled budget and time limits.
